# Wacho.mp3

Recomendador de discos: elegís una o varias bandas de referencia, géneros y décadas, y movés el dial de **Masivo** a **Under**.
El **ADN sonoro** muestra qué tienen en común las bandas que cargaste y te deja sumar esos rasgos al género.
Guardados y escuchados quedan en cada dispositivo (no se comparten).

App: https://gero77.github.io/wacho/

Datos: Last.fm (artistas parecidos, etiquetas, oyentes) y MusicBrainz (discos y años). Tapas: Cover Art Archive.

Al publicar cambios, subir `VERSION` en `sw.js`.
